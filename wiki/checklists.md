# KGAI Unified Checklist

이 문서는 여러 기관 자료를 합쳐 만든 **단일 canonical 체크리스트**다. 같은 취지의 항목은 하나로 합치고, 새 source는 기존 항목과 실질적으로 다른 내용이 있을 때만 추가한다. 세부 provenance는 `sources/`에서 확인한다.

## 사용 방법

1. 먼저 아래 **공통 체크리스트**를 본다.
2. 산출물 유형에 따라 **매체별 추가 체크포인트**를 본다.
3. 하나라도 문제가 있으면 원안 유지가 아니라 수정 대상으로 본다.
4. 근거 출처를 확인해야 할 때만 `sources/*.md`를 추적한다.

## 1. 공통 체크리스트

_근거 source: 여성가족부 2026 지침, 서울교육, 경기도, 양성평등 방송 프로그램 제작 안내서, 사건보도 참고수첩_

### 1. 성별 대표성 및 포용성

- [ ] 특정 성별, 연령, 계층, 인종, 장애 여부만 과도하게 등장하거나 반대로 배제되지 않는가
- [ ] 전문가, 설명자, 의사결정자, 중심 인물이 특정 성별로 고정되어 있지 않은가
- [ ] 정책 대상이 남녀노소 전체인데 젊은 비장애인 중심 이미지로만 구성되어 있지 않은가
- [ ] 필요할 경우 보조장구 사용자, 다양한 연령대, 다양한 가족 형태가 자연스럽게 포함되어 있는가

### 2. 성역할 고정관념 및 편견

- [ ] 여성은 보조자·질문자·돌봄 담당, 남성은 결정자·답변자·생계부양자로 고정되어 있지 않은가
- [ ] 여성은 쇼핑·문학, 남성은 스포츠·기계처럼 관심 분야가 전통적 성역할에 따라 나뉘어 있지 않은가
- [ ] 특정 직업이나 전문성이 한 성별에만 배정되어 있지 않은가
- [ ] 여성다움/남성다움이라는 규범을 인물의 성격, 자세, 표현 방식에 강요하고 있지 않은가
- [ ] 여성=분홍, 남성=파랑, 여성=긴 머리, 남성=짧은 머리 같은 관습을 자동 반영하고 있지 않은가

### 3. 차별적 표현, 비하, 외모지상주의

- [ ] 성별을 구분하거나 열등하게 만드는 언어를 사용하고 있지 않은가
- [ ] 특정 성별을 희화화하거나 혐오 대상으로 만드는 표현을 쓰고 있지 않은가
- [ ] 외모를 성취나 전문성보다 우선 평가하고 있지 않은가
- [ ] 신체 일부를 부각하거나 인물을 성적 대상으로 소비하게 만들고 있지 않은가
- [ ] 특정 세대, 특정 인종, 특정 집단을 편견적으로 묘사하고 있지 않은가

### 4. 가족 및 관계에 대한 편견

- [ ] 가족을 부모+자녀 형태의 이른바 정상가족으로만 한정하고 있지 않은가
- [ ] 가사, 양육, 간병, 돌봄을 여성의 기본 역할로 고정하고 있지 않은가
- [ ] 한부모, 조손, 다문화, 1인 가구, 비혼, 독거 가구를 부정적이거나 결핍된 이미지로 다루고 있지 않은가

### 5. 폭력, 범죄, 피해 재현

- [ ] 가해자와 피해자를 특정 성별에 자동 배정하고 있지 않은가
- [ ] 피해자의 옷차림, 행동, 성향, 직업, 결혼 여부, 거주지, 가정환경이 범죄를 유발하거나 피해자에게 책임이 있다는 뉘앙스를 주고 있지 않은가
- [ ] 성폭력, 가정폭력, 성희롱, 성매매, 스토킹, 교제폭력을 선정적 볼거리처럼 재현하거나 가해 방법을 필요 이상으로 자세히 묘사하고 있지 않은가
- [ ] 피해를 순결 훼손, 수치, 오명처럼 표현하고 있지 않은가
- [ ] 피해자를 웅크리고 우는 모습으로만 그리는 등 '피해자다움'에 대한 편견을 강화하고 있지 않은가
- [ ] 가해자를 짐승, 늑대, 악마처럼 비정상적이고 예외적인 존재로 그려 사회구조적 문제를 개인의 병리로 바꿔놓고 있지 않은가
- [ ] '몹쓸 짓', '나쁜 손', '몰카', '성추문'처럼 가해행위의 심각성을 희석하는 표현을 쓰고 있지 않은가
- [ ] 부부, 연인, 친구 등 가까운 관계에서 벌어지는 폭력을 사소하게 축소하거나 사랑싸움처럼 다루고 있지 않은가

### 6. 최종 처리 판단

- [ ] 위 항목에 저촉되는 부분이 있으면 수정 또는 재기획 대상으로 분류했는가
- [ ] 외주 또는 협업 산출물이라면 수정 요청 기준을 명시했는가
- [ ] 공개 전 최종 검토에서 같은 오류가 반복되지 않도록 다시 점검했는가

## 2. 매체별 추가 체크포인트

### 이미지, 포스터, 카드뉴스, 리플릿

_근거 source: 서울교육, 경기도_

- [ ] 특정 성별이 화면 중앙, 전경, 크게 배치되고 다른 성별은 후경, 측면, 흐리게 배치되어 있지 않은가
- [ ] 정면 응시, 설명하는 자세, 주도하는 포즈가 특정 성별에만 몰려 있지 않은가
- [ ] 여성 캐릭터에 속눈썹, 볼터치, 치마, 분홍색을 자동 부여하고 있지 않은가
- [ ] 남성 캐릭터에 근육질, 파란색, 큰 체격, 강한 자세를 자동 부여하고 있지 않은가
- [ ] 가족 이미지가 지나치게 단일한 형태로 반복되고 있지 않은가

### 홈페이지, 픽토그램, 캐릭터, 마스코트

_근거 source: 경기도_

- [ ] 대표 이미지나 메인 배너가 특정 성별, 연령, 계층 위주로 고정되어 있지 않은가
- [ ] 픽토그램이 넥타이, 치마 같은 성별 표식을 기본값처럼 사용하고 있지 않은가
- [ ] 캐릭터 디자인이 성별 고정관념에 의존하지 않고도 구분되도록 설계되어 있는가

### 텍스트, 문구, 카피

_근거 source: 서울교육, 경기도, 방송 안내서_

- [ ] 신조어, 유행어, 혐오 표현을 무심코 차용하고 있지 않은가
- [ ] 성별을 포함한 수식어가 불필요하게 붙어 있지 않은가
- [ ] 표현 교체가 필요한 용어는 `terms/`에서 이미 정리된 권장어로 바꿨는가

### 동영상, 웹콘텐츠, 교육자료

_근거 source: 서울교육, 경기도_

- [ ] 콘티 단계에서부터 성별 대표성과 성역할 고정관념을 점검했는가
- [ ] 진행자, 인터뷰이, 전문가, 사례 인물이 성별 균형을 크게 벗어나지 않는가
- [ ] 외주 제작 과업지시서나 브리프에 이 체크리스트 준수 기준을 넣었는가

### 방송 프로그램 추가 체크포인트

_근거 source: 양성평등 방송 프로그램 제작 안내서_

- [ ] 뉴스, 토론, 교양, 예능에서 특정 성의 시각과 관점이 구조적으로 배제되지 않는가
- [ ] 패널, 인터뷰이, 전문가 섭외가 한 성별 중심으로 굳어 있지 않은가
- [ ] 남녀 공동 진행 시 한쪽은 주도, 다른 쪽은 보조나 장식 역할로만 배치되지 않는가
- [ ] 어린이 프로그램에서 이분법적 성역할을 학습시키는 대사나 설정이 없는가
- [ ] 내레이션, 자막, 좌석 배치, 카메라 시선이 성 고정관념을 강화하지 않는가
- [ ] 성범죄, 가정폭력, 교제폭력(데이트 폭력), 스토킹을 가해자 관점에서 정당화하거나 가볍게 다루지 않는가
- [ ] 성별 혐오어, 대상화 표현, 외모 열등감 조장 표현을 그대로 사용하지 않는가

### 여성폭력 사건 보도 및 사건 관련 콘텐츠

_근거 source: 사건보도 참고수첩, 여성폭력 사건보도 권고기준 1.0_

성희롱·성폭력·스토킹·가정폭력·교제폭력 사건을 다루는 보도자료, 브리핑, 기사, 방송 리포트, 사건 관련 카드뉴스·영상·캠페인에 적용한다. 공통 체크리스트 5절과 함께 본다.

#### 취재 및 인터뷰 단계

- [ ] 소속과 신분을 먼저 밝히고 취재 목적을 분명히 설명했는가
- [ ] 신원 노출을 방지하는 취재·보도 방식을 피해자에게 충분히 설명했는가
- [ ] 보도로 예상되는 2차 피해를 충분히 설명하고 보도 동의를 받았는가
- [ ] 삽화, 자료화면, 재연이 활용될 수 있다는 점까지 구체적으로 알리고 동의를 받았는가
- [ ] 피해자가 인적 사항을 드러내는 방식을 원할 때, 예상되는 부작용을 충분히 알렸는가
- [ ] 인터뷰 거부 의사를 존중했는가. 거부 사실 자체를 부정적으로 언급하고 있지 않은가
- [ ] 피해자가 인터뷰 상황임을 모른 채 한 말을 동의 없이 사용하고 있지 않은가
- [ ] 사적 공간 침입, 무단 촬영, 사생활 기록물(SNS, 일기, 편지, 사진, 생활기록부) 촬영으로 자료를 얻고 있지 않은가
- [ ] 사건의 본질과 무관한 사적 질문, 호기심에만 기반한 질문을 배제했는가
- [ ] '왜 그때 거기 있었나', '왜 저항하지 않았나', '왜 이제야 말하나'처럼 피해자다움 편견이나 입증책임 전가에 기반한 질문을 배제했는가
- [ ] 편집 과정에서 피해자의 진의가 왜곡되지 않도록 확인했는가

#### 신원 노출 방지

- [ ] 이름, 얼굴, 나이, 주소, 학교, 직업, 용모 등 직접 정보를 공개하고 있지 않은가
- [ ] 나이대, 직업, 지역, 근무지, 범죄 발생장소, 가해자와의 관계 등 간접 정보의 조합으로 신원이 특정되지 않는가
- [ ] 모자이크나 음성변조를 했다는 이유로 간접 노출 점검을 생략하고 있지 않은가
- [ ] 주변인(가족, 동료, 주민, 관계자) 인터뷰 내용으로 피해자가 특정되지 않는가
- [ ] 다른 매체 보도와 합쳐졌을 때 피해자가 특정될 가능성을 고려했는가
- [ ] 제보자, 고소·고발인, 증인의 신원이 노출될 정보를 동의 없이 담고 있지 않은가
- [ ] 가정폭력 사건에서 가해자 정보 공개로 피해자 신원이 역추적되지 않는가
- [ ] 피해자가 스스로 피해 사실을 밝혔더라도, 동의 없이 신상정보를 부각하고 있지 않은가
- [ ] 실명이나 얼굴 공개를 종용하고 있지 않은가

#### 기사 작성 및 편집

- [ ] 당사자에게 미치는 영향과 사회적 의미를 견주어 볼 때 보도할 가치가 있는가
- [ ] '○○○ 사건'처럼 피해자를 주체로 한 사건명을 쓰고 있지 않은가
- [ ] 사건과 무관한 피해자의 사생활(습관, 기호, 질병, 장래희망, 주변 평판, 과거 사진·영상)을 담고 있지 않은가
- [ ] 피해 상태나 피해 사실을 지나치게 자세히 또는 선정적으로 묘사하고 있지 않은가
- [ ] 가해 방법, 범행 과정, 수사기법을 모방이 가능할 정도로 상세히 설명하고 있지 않은가
- [ ] 제목에 자극적 표현이나 가해자·누리꾼의 발언을 그대로 인용하고 있지 않은가
- [ ] 사건과 무관한 가해자의 학력, 경력, 평판, 근황, 재능, 업적을 부각해 사건의 심각성을 희석하고 있지 않은가
- [ ] 가해 원인을 가해자의 정신질환, 성욕, 이성과의 접촉 부족 등으로 왜곡하고 있지 않은가
- [ ] 사건을 가해자와 피해자의 연애·성적 관계나 사적 대립 구도로 다루고 있지 않은가

#### 삽화, 사진, 영상

- [ ] 피해자를 웅크리거나 우는 모습으로 표현해 무기력·나약함의 편견을 강화하고 있지 않은가
- [ ] 가해자를 빨간 손, 늑대, 악마 등 비정상적 존재로 표현하고 있지 않은가
- [ ] 피해자를 성적 행위의 대상으로 인식하게 하는 선정적 삽화를 쓰고 있지 않은가
- [ ] 범행 장면 CCTV·영상을 편집 없이 사용하거나 범행 내용을 재연하고 있지 않은가
- [ ] 모자이크·블러 처리했더라도 잔인함이나 공포감을 주는 자극적 자료가 되지 않는가
- [ ] 사건과 연관성이 낮은 자극적 자료화면을 쓰고 있지 않은가
- [ ] 피해자가 아동·청소년인 사건에서 범행 장면을 재연하거나 실제 영상을 쓰고 있지 않은가
- [ ] 취재·촬영·편집 담당자가 함께 선정성 여부를 점검했는가

#### 정확성과 사후 조치

- [ ] 확인되지 않은 일방의 주장을 확정된 사실처럼 전달하고 있지 않은가
- [ ] 타사 보도를 받아 쓰면서 최소한의 사실확인을 거쳤는가
