# KGAI Unified Checklist

이 문서는 여러 기관 자료를 합쳐 만든 **단일 canonical 체크리스트**다. 같은 취지의 항목은 하나로 합치고, 새 source는 기존 항목과 실질적으로 다른 내용이 있을 때만 추가한다. 세부 provenance는 `sources/`에서 확인한다.

## 사용 방법

1. 먼저 아래 **공통 체크리스트**를 본다.
2. 산출물 유형에 따라 **매체별 추가 체크포인트**를 본다.
3. 하나라도 문제가 있으면 원안 유지가 아니라 수정 대상으로 본다.
4. 근거 출처를 확인해야 할 때만 `sources/*.md`를 추적한다.

## 1. 공통 체크리스트

_근거 source: 여성가족부 2026 지침, 서울교육, 경기도, 양성평등 방송 프로그램 제작 안내서_

### 1. 성별 대표성 및 포용성

- [ ] 특정 성별, 연령, 계층, 인종, 장애 여부만 과도하게 등장하거나 반대로 배제되지 않는가
- [ ] 전문가, 설명자, 의사결정자, 중심 인물이 특정 성별로 고정되어 있지 않은가
- [ ] 정책 대상이 남녀노소 전체인데 젊은 비장애인 중심 이미지로만 구성되어 있지 않은가
- [ ] 필요할 경우 보조장구 사용자, 다양한 연령대, 다양한 가족 형태가 자연스럽게 포함되어 있는가

### 2. 성역할 고정관념 및 편견

- [ ] 여성은 보조자·질문자·돌봄 담당, 남성은 결정자·답변자·생계부양자로 고정되어 있지 않은가
- [ ] 여성은 쇼핑·문학, 남성은 스포츠·기계처럼 관심 분야가 전통적 성역할에 따라 나뉘어 있지 않은가
- [ ] 특정 직업이나 전문성이 한 성별에만 배정되어 있지 않은가
- [ ] 여성다움/남성다움이라는 규범을 인물의 성격, 자세, 표현 방식에 강요하고 있지 않은가
- [ ] 여성=분홍, 남성=파랑, 여성=긴 머리, 남성=짧은 머리 같은 관습을 자동 반영하고 있지 않은가

### 3. 차별적 표현, 비하, 외모지상주의

- [ ] 성별을 구분하거나 열등하게 만드는 언어를 사용하고 있지 않은가
- [ ] 특정 성별을 희화화하거나 혐오 대상으로 만드는 표현을 쓰고 있지 않은가
- [ ] 외모를 성취나 전문성보다 우선 평가하고 있지 않은가
- [ ] 신체 일부를 부각하거나 인물을 성적 대상으로 소비하게 만들고 있지 않은가
- [ ] 특정 세대, 특정 인종, 특정 집단을 편견적으로 묘사하고 있지 않은가

### 4. 가족 및 관계에 대한 편견

- [ ] 가족을 부모+자녀 형태의 이른바 정상가족으로만 한정하고 있지 않은가
- [ ] 가사, 양육, 간병, 돌봄을 여성의 기본 역할로 고정하고 있지 않은가
- [ ] 한부모, 조손, 다문화, 1인 가구, 비혼, 독거 가구를 부정적이거나 결핍된 이미지로 다루고 있지 않은가

### 5. 폭력, 범죄, 피해 재현

- [ ] 가해자와 피해자를 특정 성별에 자동 배정하고 있지 않은가
- [ ] 피해자의 옷차림, 행동, 대응 방식이 범죄를 유발했다는 뉘앙스를 주고 있지 않은가
- [ ] 성폭력, 가정폭력, 성희롱, 성매매를 선정적 볼거리처럼 재현하고 있지 않은가
- [ ] 피해를 순결 훼손, 수치, 오명처럼 표현하고 있지 않은가
- [ ] 부부, 연인, 친구 등 가까운 관계에서 벌어지는 폭력을 사소하게 축소하고 있지 않은가

### 6. 최종 처리 판단

- [ ] 위 항목에 저촉되는 부분이 있으면 수정 또는 재기획 대상으로 분류했는가
- [ ] 외주 또는 협업 산출물이라면 수정 요청 기준을 명시했는가
- [ ] 공개 전 최종 검토에서 같은 오류가 반복되지 않도록 다시 점검했는가

## 2. 매체별 추가 체크포인트

### 이미지, 포스터, 카드뉴스, 리플릿

_근거 source: 서울교육, 경기도_

- [ ] 특정 성별이 화면 중앙, 전경, 크게 배치되고 다른 성별은 후경, 측면, 흐리게 배치되어 있지 않은가
- [ ] 정면 응시, 설명하는 자세, 주도하는 포즈가 특정 성별에만 몰려 있지 않은가
- [ ] 여성 캐릭터에 속눈썹, 볼터치, 치마, 분홍색을 자동 부여하고 있지 않은가
- [ ] 남성 캐릭터에 근육질, 파란색, 큰 체격, 강한 자세를 자동 부여하고 있지 않은가
- [ ] 가족 이미지가 지나치게 단일한 형태로 반복되고 있지 않은가

### 홈페이지, 픽토그램, 캐릭터, 마스코트

_근거 source: 경기도_

- [ ] 대표 이미지나 메인 배너가 특정 성별, 연령, 계층 위주로 고정되어 있지 않은가
- [ ] 픽토그램이 넥타이, 치마 같은 성별 표식을 기본값처럼 사용하고 있지 않은가
- [ ] 캐릭터 디자인이 성별 고정관념에 의존하지 않고도 구분되도록 설계되어 있는가

### 텍스트, 문구, 카피

_근거 source: 서울교육, 경기도, 방송 안내서_

- [ ] 신조어, 유행어, 혐오 표현을 무심코 차용하고 있지 않은가
- [ ] 성별을 포함한 수식어가 불필요하게 붙어 있지 않은가
- [ ] 표현 교체가 필요한 용어는 `terms/`에서 이미 정리된 권장어로 바꿨는가

### 동영상, 웹콘텐츠, 교육자료

_근거 source: 서울교육, 경기도_

- [ ] 콘티 단계에서부터 성별 대표성과 성역할 고정관념을 점검했는가
- [ ] 진행자, 인터뷰이, 전문가, 사례 인물이 성별 균형을 크게 벗어나지 않는가
- [ ] 외주 제작 과업지시서나 브리프에 이 체크리스트 준수 기준을 넣었는가

### 방송 프로그램 추가 체크포인트

_근거 source: 양성평등 방송 프로그램 제작 안내서_

- [ ] 뉴스, 토론, 교양, 예능에서 특정 성의 시각과 관점이 구조적으로 배제되지 않는가
- [ ] 패널, 인터뷰이, 전문가 섭외가 한 성별 중심으로 굳어 있지 않은가
- [ ] 남녀 공동 진행 시 한쪽은 주도, 다른 쪽은 보조나 장식 역할로만 배치되지 않는가
- [ ] 어린이 프로그램에서 이분법적 성역할을 학습시키는 대사나 설정이 없는가
- [ ] 내레이션, 자막, 좌석 배치, 카메라 시선이 성 고정관념을 강화하지 않는가
- [ ] 성범죄, 가정폭력, 데이트 폭력을 가해자 관점에서 정당화하거나 가볍게 다루지 않는가
- [ ] 성별 혐오어, 대상화 표현, 외모 열등감 조장 표현을 그대로 사용하지 않는가
