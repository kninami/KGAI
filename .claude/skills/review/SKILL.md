# Review — 산출물 성인지 감수성 검토

## 출력 서식

**검토 결과는 반드시 `TEMPLATE.md` 서식으로 낸다.** 작업을 시작하기 전에 이 스킬 디렉터리의 `TEMPLATE.md` 를 읽고, 그 절 구성과 작성 규칙을 그대로 따른다. 서식을 임의로 줄이거나 절을 빼지 않는다.

지적이 한 건뿐이거나 이상이 없어도 서식은 유지한다. 서식이 고정되어야 여러 검토 결과를 나란히 비교하고 이력으로 쌓을 수 있다.

## 절차

### 1. 대상과 유형 파악

무엇을 검토하는지, 어떤 매체인지 먼저 정한다. 매체가 정해져야 적용할 체크리스트 섹션이 정해진다.

파일이 아니라 붙여넣은 텍스트·이미지일 수도 있다. 이미지는 실제로 열어서 본다.

### 2. 기준 문서 읽기

```
wiki/checklists.md   → 공통 체크리스트 + 해당 매체별 섹션
wiki/guidelines.md   → 관련 장 (지적 사유를 설명할 때 필요)
wiki/terms/          → 용어 문제가 보일 때 해당 페이지
```

매체별 섹션이 여러 개 걸리면 모두 적용한다. 예를 들어 폭력 사건을 다루는 카드뉴스는 `이미지, 포스터, 카드뉴스, 리플릿` 과 `여성폭력 사건 보도 및 사건 관련 콘텐츠` 를 함께 본다.

### 3. 대조

공통 체크리스트를 처음부터 훑고, 이어서 매체별 항목을 훑는다. 저촉 가능성이 있는 지점마다 다음을 특정한다.

- 산출물의 어느 지점인가 (페이지, 장면, 문단, 줄)
- 어느 체크리스트 항목에 걸리는가
- 왜 문제인가 — 가이드라인의 어느 원칙으로 설명되는가

### 4. 용어 교정

`terms/` 에 등록된 표현이 그대로 쓰였는지 확인하고 권장어로 바꾼다. 등록되지 않은 표현이라도 교정이 필요하다고 판단하면, 그 사실을 밝히고 term 페이지 신설을 제안한다.

### 5. 근거 추적

각 지적에 대해 `wiki/sources/*.md` 까지 내려가, 어느 원본이 그 판단을 뒷받침하는지 밝힌다. 체크리스트 항목의 `_근거 source:_` 표기에서 출발해 해당 source summary의 "통합본에 새로 반영한 내용" 을 확인하면 된다.

한 지적에 여러 source가 걸리면 판단을 가장 구체적으로 뒷받침하는 쪽을 든다.

### 6. 수정본 제시

지적으로 끝내지 않는다. 반영된 완성본을 낸다. 이미지·영상처럼 텍스트로 대체할 수 없으면 요소별 수정 지시서로 낸다.

## 판단 기준

- **근거 없는 지적을 만들지 않는다.** canonical 문서에 근거가 없으면 그 사실을 밝히고 판단 보류로 내린다. 일반론이나 개인적 감각으로 지적하지 않는다.
- **현실 반영과 편견 재생산을 구분한다.** 정책 대상이 명확해 특정 집단만 등장하는 것이 정당한 경우가 있다. 다만 그 경우에도 표현 방식이 편견을 강화하는지는 따로 본다.
- **성비 1:1이 목표가 아니다.** 숫자보다 자동화된 편중을 끊는 것이 핵심이다.
- **건수를 채우지 않는다.** 이상이 없으면 이상 없다고 한다.
- **심각도를 구분한다.** 체크리스트 직접 저촉만 `필수 수정` 이다.

## 검토 중 알게 된 것

검토하다가 위키에 반영할 만한 것을 발견하면 — 반복되는 오류 유형, `terms/` 에 없는 차별 표현, canonical 문서의 빈 구멍 — 검토 결과 끝에 별도로 언급한다. 사용자가 요청하지 않았는데 위키를 고치지는 않는다.
